# dsh-readwrite-hub（读写字间）

> 为 **DeepSeek Harness** Web 界面打造的小说写作与阅读一体插件：在侧边栏直接码字、翻页读长篇小说。
> 按网络小说的阅读习惯设计——可调的字体/字号/行距/边距/纸张背景、横线格稿纸、按字分页、自动记忆阅读进度。

本插件是在 [`3911ee/dsh-workspace-explorer`](https://github.com/3911ee/dsh-workspace-explorer)
（MIT 协议开源）基础上二次开发的魔改分支：完整保留其文件管理能力，并新增小说阅读模式。
我们在此**明确承认并致谢上游项目**，详见下文「致谢与许可」。

---

## 亮点

- **写作与阅读一体**：同一个文件，点「码字」进入稿纸模式，点「阅读」进入书籍模式，排版偏好完全共享。
- **符合网络小说阅读习惯**：
  - 按字分页（段落可跨页），页面始终填满，不留大段空白；只有新章节另起一页。
  - 自动记忆阅读进度，重开文件即续读；进度书签永远置顶，显示记录时间。
  - 「返回原进度」胶囊：跳页/搜索后一键回到原位置；连续翻 3 页后自动确认新位置。
  - 支持上百万字 TXT 长文（4 MiB 内秒开、按需渲染，翻页流畅）。
- **可编辑的排版偏好**（码字/阅读共用）：
  - 字体：衬线 / 楷体 / 无衬线 / 等宽
  - 字号（A- / A+）、行距（- / +）、页边距（- / +）
  - 纸张背景：默认 / 米色 / 浅绿 / 蓝色（护眼），暗色主题实时切换
  - 码字模式额外提供**横线格稿纸**（随文字滚动的标准横线格，可开关）
- **书签与目录**：一键加书签；自动解析章节（支持「第一章」「序章」「番外」「Chapter N」等十余种格式），点击直达。
- **文件管理**：VS Code 风格双栏文件面板——新建文件/文件夹、行内重命名、复制/粘贴/删除、
  右键菜单（含「在资源管理器中打开」）、大文件只读保护、编辑自动保存（码字模式）。
- **与对话联动**：文件一键「添加到对话」成为输入框胶囊；AI 消息中的文件引用点击后在插件内直接打开。

## 安装

### 方式一：npm（推荐）

```bash
dsh plugin --profile web add dsh-readwrite-hub
```

### 方式二：GitHub

```bash
dsh plugin --profile web add github:Nth-5620/dsh-readwrite-hub
```

安装后**重启 `dsh web`**，并**硬刷新浏览器**（Ctrl+Shift+R）。
侧边栏底部出现「工作区文件」按钮（悬停提示「工作区文件」）即加载成功。

> 开发版：将本仓库的 `lib/` 放入 `~/.dsh/profiles/web/node_modules/dsh-readwrite-hub/` 并注册 bundle 即可，无需构建。

## 使用

1. 在侧边栏文件面板打开一个文本文件（.txt / .md）。
2. 工具栏点「码字」进入写作模式，或点「阅读」进入书籍模式。
3. 阅读模式下：
   - 底部进度条点击任意位置跳转；「上一页 / 下一页」与键盘（PageUp/PageDown/↑/↓/Home/End/空格）翻页。
   - 底部输入框直接输入页码回车跳页。
   - 「目录」列出全部章节，点击直达；「书签」查看/跳转/删除书签。
   - 进度自动按文件保存到 `~/.dsh/readwrite-hub/state.json`，重开自动续读。

## 架构

- **宿主面**（`lib/index.js`）：Cordis 插件，注册 `/readwrite-hub-api/*` REST 接口
  （list/read/write/rename/mkdir/newfile/copy/move/delete/reveal/state），
  `state` 原子读写 `~/.dsh/readwrite-hub/state.json`；提供 rc.8 设置槽。
- **客户端面**（`lib/client.js`）：`__ModuleLoader__` 单文件浏览器 bundle，
  注册侧边栏入口与设置面板；阅读模式为 `ReadingView` 组件
  （字符级分页 = CJK 字宽校准 + 字符切片，页面与渲染严格一致）。

## 兼容性

- DeepSeek Harness `0.1.0-rc.8+`，Node.js 20+。
- 纯前端无原生依赖；Windows / WSL / macOS 均可运行（「在资源管理器中打开」依赖 WSL 环境）。
